# ⚒️ DasikLibrary NF

**Summary:** NeoForge implementation of Dasik Library.

**No Backports:** This mod targets **Minecraft 26.+**. Older versions are unsupported.

---

## 📦 Install

1. Install **[NeoForge](https://neoforged.net/)**.
2. Download $KebabModId-1.0.0.jar and place it in your mods folder.
3. Launch the game.
