# Руководство по интеграции модов-потребителей

| Мод-потребитель | Особенности интеграции |
| :--- | :--- |
| **Better Dogs** | Динамика стаи, тактические команды горна, генетическое масштабирование |
| **Natural Reproduction** | Проверка родословной, прогноз риска инбридинга, характеристики размера |
| **Collapsible Game Rule Screen** | Жирные заголовки категорий (`§l`), динамическая регистрация правил |
| **Bat Ecology** | Стратегии кружения воздушной стаи (`FlockType.AERIAL`) |
| **Ore Amplifier** | Стохастическое масштабирование генерации руд (`StochasticUtil`) |

---

## 🛠️ Пошаговый чек-лист интеграции

1. **Добавление зависимости**: Объявите `"dasik-library": "*"` в `fabric.mod.json`.
2. **Реализация интерфейсов**: Реализуйте `SocialEntity` или `GroupMember` на мобах.
3. **Регистрация GameRules**: Вызовите `DynamicGameRuleManager.registerBoolean` / `registerInt` при инициализации.
4. **Использование фасада генетики**: Запрашивайте характеристики через `DasikAnimalGeneticsAPI`.
