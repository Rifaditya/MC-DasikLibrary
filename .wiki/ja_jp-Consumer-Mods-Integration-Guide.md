# 下流 Mod 連携・統合ガイド

## 🧩 公式下流 Mod 一覧

| Mod 名称 | Dasik Library の活用領域 |
| :--- | :--- |
| **Better Dogs** | イヌの遺伝学、群れ Boids アルゴリズム、警備モード、専用 GameRules。 |
| **Natural Reproduction** | 家系図システム、近親交配リスク予測、動的サイズスケーリング。 |
| **Collapsible Game Rule Screen** | 太字ヘッダー（`§l`）付き動的 GameRules カテゴリの折りたたみ表示。 |
| **Bat Ecology** | 飛行型 Boids アルゴリズムによるコウモリの自然な群れ飛行。 |
| **Ore Amplifier** | 鉱石生成確率の計算に stochastics ユーティリティを使用。 |
