## 🧩 Mods Consommateurs Officiels

| Mod Consommateur | Description & Utilisation de Dasik Library |
| :--- | :--- |
| **Better Dogs** | Exploite la génétique canine, la meute Boids, la garde sentinelle et les GameRules dédiées. |
| **Natural Reproduction** | Utilise l'arbre généalogique, les risques de consanguinité et la taille adaptative. |
| **Collapsible Game Rule Screen** | Organise les catégories de GameRules dynamiques avec en-têtes gras `§l`. |
| **Bat Ecology** | Utilise l'algorithme Boids aérien pour le vol coordonné des chauves-souris. |
| **Ore Amplifier** | Exploite les fonctions stochastiques pour les tirages de génération de minerais. |
